# ARES Binder Environment

Click the badge below to launch this environment in Binder:

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/acliu/ares_environment/HEAD)

## What this is

A reproducible Jupyter environment for running the ARES (Accelerated Reionization Era Simulations) package.

## Contents

- Python 3.10 environment
- Compatible NumPy/SciPy stack
- ARES installed from GitHub
- JupyterLab interface

## Getting started

Open `notebooks/ARES_demo.ipynb` and run the example cells.
